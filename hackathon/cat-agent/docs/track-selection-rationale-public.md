# Week 3｜赛道选择说明

我选择 `Z.AI｜Web3 × Long-Horizon Task` 作为 `Cat-Agent` 的主赛道。  
`Cat-Agent` 不是一个单点分类器，而是一个需要持续观察、多步判断、两轮确认、规则校验和主人解释反馈的长任务链路，这和 Z.AI 强调的长程任务拆解与多步工具调用非常贴合。  
我的项目核心不是“让宠物自己下单”，而是让 Agent 在多模态信号、风控边界和主人确认之间完成一个可解释、可审计的决策闭环。  
Week 4 我会优先做 `event trigger -> cloud reasoning -> confirmation -> risk engine -> owner approval -> simulated order` 这一条最小可验证路径，再视时间补测试网审计层。
